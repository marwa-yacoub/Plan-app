# Plan-App

Ein einfaches Planungsprogramm in Python für die Konsole.
Ich habe es als Anfängerin programmiert, um meine Aufgaben zu organisieren.

## Funktionen

- Neue Aufgabe hinzufügen
- Alle Aufgaben anzeigen
- Aufgabe löschen
- Aufgaben werden in der Datei `aufgaben.txt` gespeichert und beim nächsten Start wieder geladen

## So startest du das Programm

1. Python installieren (Version 3)
2. Die Datei `plan.py` herunterladen
3. Die Datei in IDLE öffnen und mit F5 starten
   (oder im Terminal: `python plan.py`)
